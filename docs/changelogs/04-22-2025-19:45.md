Added a complete implementation of the Test Metadata component for visualizing code block metadata, including comprehensive test coverage.

- `/components/ui/test-metadata.tsx`:

  - Added tabbed interface for configuring different aspects of code blocks

- `/jest.config.js`:
  - Updated test pattern to include .tsx files

### Features:

- Interactive code block metadata testing tool with four main sections:
  1. **Code**: Edit code content and select language
  2. **Metadata**: Configure model, run IDs, step info, cache keys, etc.
  3. **Changes Highlight**: Toggle and configure visualization of code changes
  4. **Display Options**: Toggle metadata display

- Real-time preview showing how code blocks will render with the current settings
- Support for all metadata fields defined in the CodeBlockCode component
- Complete control over changes highlighting with configurable parameters
- Well-structured, responsive layout using shadcn UI components

### Technical Details:

- Implemented using React hooks for state management
- Used shadcn UI components for a consistent look and feel
- Properly typed using TypeScript with strict type checking
- Added comprehensive test suite with jsdom for DOM testing
- All styling uses Tailwind CSS classes for consistency with the rest of the application
- Used shadcn UI Card, Tabs, Switch, and Form components for layout and interaction

This implementation provides developers with a valuable tool for testing and debugging code block appearance with different metadata configurations, making it easier to ensure metadata displays correctly across the application.
