# Change Log 5/9/2025 11:00 AM

## Changes
- **App Metadata**: Updated application metadata and added a custom favicon for improved branding and browser identification.
- **Batch Deletion**: Implemented functionality to delete batches of records efficiently through a new API route.
- **Monte Carlo Visualization**: Optimized the visualization for mobile devices with enhanced touch handling for better user experience.
- **Package Updates**: Updated Next.js from version 15.2.4 to 15.3.0 and other related dependencies.
- **Sentry Configuration**: Migrated Sentry configuration from TypeScript to JavaScript for improved compatibility.
- **Next.js Configuration**: Added optimized Next.js configuration to improve application performance.
- **Database Migration**: Enhanced Supabase database migrations with improved trigger handling.
- **PostgREST Compatibility**: Added compatibility functions for PostgREST to improve API interactions.

## Technical Details
The migration of Sentry configuration from TypeScript to JavaScript resolves several compatibility issues with Next.js 15.3.0. The new batch deletion API route (`/api/delete-batch`) allows for more efficient data management by supporting bulk operations with proper error handling. 

The Monte Carlo visualization component was refactored to handle touch events properly on mobile devices, improving the interaction model significantly. This includes better gesture recognition for zooming and panning actions.

Database migration improvements include enhanced trigger handling for maintaining data integrity, with additional functions for PostgREST compatibility that allow for more efficient API queries. These changes optimize the interaction between the Next.js frontend and the Supabase backend, reducing latency and improving overall application performance.

The Next.js configuration now includes improved asset optimization, streaming capabilities, and memory management for better performance across different deployment environments.
