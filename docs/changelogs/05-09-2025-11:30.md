# Changelog: 05-09-2025 11:30

## Fixed: Point Selection in Monte Carlo 3D View During Camera Movement

### Issue
When moving or rotating the camera in the 3D Monte Carlo visualization, point selection would not persist. Selected points and their connection lines would lose their highlight state during camera movement.

### Technical Changes

1. **Points Component Updates**:
   - Added check to prevent click events during camera movement, preserving existing selection
   - Enhanced the `updatePointColors` function to run more frequently (50ms vs 100ms)
   - Improved the scale calculation to ensure selected points remain visually distinct
   - Added better logging for selection state

2. **Camera Controls Updates**:
   - Ensured the `isCameraMovingRef` flag is properly set during camera movement
   - Added a second invalidation step after camera movement stops to refresh the visualization
   - Shortened the movement detection interval for more responsive updates
   - Maintained the `preventAutoDeselect` flag to preserve selection state

3. **Selection Persistence**:
   - Made sure selected points maintain their highlighted state during and after camera movements
   - Ensured selected points and their connected points remain visually distinct

### Technical Implementation
The fix preserves the selection state in the React component state while improving the visual updating mechanism to ensure highlighted points remain visible during camera movement. The updates also improve the responsiveness of the controls by using shorter intervals for state checking and more frequent visual refreshes.
