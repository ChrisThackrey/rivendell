# Changelog: 05-09-2025 12:00

## Enhanced: Cluster Cube Selection in Monte Carlo Visualization

### Feature
When a cluster cube is selected in the 3D view, all points contained within that cluster's bounding box now display their detail cards in the side panel. This provides a comprehensive view of all runs in the selected cluster.

### Technical Changes

1. **DetailsPanel Component**:
   - Modified both `DetailsPanel.tsx` and `details-panel.tsx` to display all points from selected clusters
   - Removed the 10-point display limit that previously truncated large clusters
   - Added visual indicators to highlight when a point is both in a selected cluster and is the currently selected point

2. **Cluster Selection Logic**:
   - Enhanced `toggleClusterSelection` function to properly handle selected points and cluster points
   - Improved camera focus behavior to show all points in selected clusters
   - Added detailed console logging for better debugging

3. **State Management**:
   - Implemented missing effect hooks to properly update filtered data, closest points, and selected cluster points
   - Enhanced ESC key handler for consistent deselection behavior
   - Improved the relationship between selected points and cluster points

4. **Camera and Visualization**:
   - Modified focus camera function to properly display all points in selected clusters
   - Ensured selected points within clusters remain highlighted

### Technical Implementation
The implementation maintains the existing cluster selection mechanism but enhances it to ensure all points within a selected cluster's bounding box are properly displayed in the details panel. This provides a more comprehensive view of the data and allows users to quickly inspect all runs within a cluster, rather than just a limited sample.
