# Consolidated Supabase Schema and Migrations into Single Initial Migration

- Created `supabase/migrations/00001_initial_rivendell.sql` by concatenating `supabase/schema.sql` and all existing migration files to represent the current database schema in one script.
- Updated `supabase/config.toml`:
  - Removed invalid `[database]` key under `[db]` section.
  - Added a proper `[database]` section at the end for `migrationsDatabaseUrl`.
- Enabled easy reconstruction of the Rivendell Supabase database by running:
  ```bash
  supabase db reset --project-ref rivendell
  supabase db migrate up
  ```
