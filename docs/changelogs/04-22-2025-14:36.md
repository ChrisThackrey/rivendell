## Runtime Error Fixes and Code Refactoring

### Changes Made
- **Fixed Runtime Error in Monte Carlo Page**:

- **Import and Reference Corrections**:

### Technical Implementation
The implementation resolves a critical Next.js runtime error related to the incorrect usage of the `revalidate` option in a client component. The fix properly separates client and server concerns by moving configuration to the appropriate components.

Additionally, type safety improvements throughout the codebase enhance maintainability and prevent potential runtime errors, especially when dealing with optional fields and external library integrations. The `CodeFile` type restructuring provides a more scalable approach to metadata storage.
